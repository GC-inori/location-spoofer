# v1.0.7

发布日期：2026-08-22

## 主要更新

- **全新半透明双栏底栏**：重构为「定位 + 配置」双 Tab 架构，采用毛玻璃半透明浮动导航栏，页面切换零延迟常驻不销毁地图。
- **长按选点与精确街道描述**：移除了多余的缩放与跳转按钮及中心十字标；支持地图长按任意位置落点或搜索落点，锚点下方展示精确到街道号的详细位置。
- **智能搜索联想**：去除顶部三点菜单，接入实时输入联想，可在配置页自定义展示条数（X）与最大联想数（Y）。
- **最近使用收藏抽屉**：底部主控卡片上方提供上拉抽屉，自动按使用频次与时间汇总展示最近收藏地点，支持字数智能省略。
- **完整分组收藏管理**：配置页新增收藏管理，支持自定义多分组、折叠展开、长按拖拽排序与跨组移动、坐标详情弹窗（支持长按一键复制 GCJ-02 与 WGS-84 坐标）。
- **全链路流畅度优化**：逆地理编码全异步非阻塞，数据持久化防抖写入，确保 60/120fps 丝滑交互。

## 兼容性说明

- 原有收藏数据在升级后会自动无痛迁移至「默认分组」，历史坐标与名称完整保留。
- 蜂窝网络打卡请使用「第三方代理模式」，并在对应客户端（如 Shadowrocket）中开启 HTTPS 解密。

## 自签安装

- Release 附件为未签名 IPA，安装前需要自行签名（可使用爱思助手、牛蛙助手、Sideloadly 或 Impactor）。
- 免费 Apple ID 签名通常有 7 天有效期，到期后重新签名即可。
