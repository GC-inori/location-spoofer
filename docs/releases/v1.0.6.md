# v1.0.6

发布日期：2026-08-21

## 主要更新

- 融合 mekos 的拦截范围：除 `gs-loc.apple.com` / `gs-loc-cn.apple.com` 外，增加 `gsp-ssl.ls.apple.com`、`bluedot.is.autonavi.com` 及其 DNS 别名。
- 第三方模块增加 Prepare 请求脚本，将 `Accept-Encoding` 设为 `identity`，减少 gzip 导致的改包失败。
- APP 模式 Go 代理同步识别上述域名，并对 WLOC 请求关闭压缩。
- 模块订阅与脚本地址改为本仓库 `GC-inori/location-spoofer`。
- 模块订阅版本升为 `1.0.6`，避免代理客户端继续使用旧缓存。

## 兼容性说明

- 仍只改写网络定位（Wi-Fi / 基站经 Apple WLOC 返回的坐标），不修改 GPS 硬件。
- APP 模式仍仅覆盖当前 Wi-Fi 手动 HTTP 代理；蜂窝网请使用第三方代理模式。
- 第三方模块必须重新导入；旧订阅仍指向上游仓库时不会获得本次拦截扩展。

## 自签安装

- Release 附件为未签名 IPA，安装前需要自行签名。
- 可使用免费 Apple ID 和 Impactor 完成签名安装，无需付费开发者账号。
- 签名时请保留 Bundle ID `com.paopaolabs.location-spoofer`、App Group `group.com.paopaolabs.location-spoofer` 及原有 entitlements。
- 免费 Apple ID 签名通常只有 7 天有效期，到期后需要重新签名安装。
